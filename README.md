![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgrey)

**Umbra** — локальная десктоп-утилита для Windows, macOS и Linux, предназначенная для **анонимизации** юридических документов (`.docx`, `.pdf`, `.xlsx`, `.txt`, `.csv`, `.html`). Старый бинарный `.doc` намеренно не открывается: сначала сохраните его как `.docx` без макросов. Программа заменяет найденные чувствительные данные на категорийные метки (например, `[ФИО_1]`, `[ОРГАНИЗАЦИЯ_2]`) и умеет подставлять их обратно в ответ ИИ. Формат `.md` используется для безопасного текстового обмена с ИИ.

![Umbra Screenshot](src/screenshot.jpg)

## ✨ Особенности
* **Перетащите документ в окно:** основной способ работы — Drag-and-Drop (на Windows). Кнопка «Выбрать файл» работает везде, включая macOS и Linux.
* **Локальная обработка:** само приложение не отправляет документы в сеть. Передача результата внешнему ИИ выполняется только пользователем через буфер обмена или загрузку файла.
* **Безопасный барьер:** внешние ссылки, макросы, вложения, формулы и непрозрачные OOXML-части отклоняются. HTML и CSV преобразуются в обычный UTF-8 текст.
* **PDF становится документом Word:** абзацы и таблицы восстанавливаются по координатам, результат — `.docx`, а не простыня текста. Собирается новый файл с нуля, поэтому активное содержимое PDF через границу не переезжает.
* **Контролируемое восстановление:** рядом с результатом создаётся паспорт `*.umbra.json` без карты подстановки и содержимого документа; он связывает настройки с хешем неизменённого оригинала.
* **В папке остаётся порядок:** после восстановления рядом с оригиналом остаётся только `[UMBRA] <имя>` — паспорт, `[ANON]`-файл и ответ ИИ удаляются.
* **Ограничения распознавания:** автоматическая анонимизация не гарантирует обнаружение всех возможных персональных данных. Проверяйте обезличенный текст перед отправкой третьей стороне.

## 💻 Технологии
* **Язык:** Python 3.14 (64-бит)
* **Интерфейс:** `customtkinter`, Drag-and-Drop на Windows через `windnd`
* **NLP (Обработка текста):** `navec` (эмбеддинги), `slovnet` (NER), `razdel` (проект Natasha)
* **Работа с документами:** `python-docx`, `pdfplumber` и `pypdf` (PDF → DOCX), `openpyxl`, `markdown-it-py`
* **Взаимодействие с ОС:** `pywin32` (буфер обмена на Windows)
* **Сборка:** `PyInstaller` (в один файл `Umbra.exe` для Windows, `Umbra.app` для macOS и `Umbra` для Linux)

## 📁 Структура проекта
* `src/` — папка со скриптами, моделями и исходниками интерфейса.
*(Скомпилированные файлы создаются в корневой папке при запуске сборки)*

## 🚀 Установка и запуск (для пользователей)

1. Перейдите в раздел **Releases** на GitHub.
2. Скачайте архив, подходящий для вашей операционной системы (`Umbra-Windows.zip`, `Umbra-macOS.zip` или `Umbra-Linux.zip`), и распакуйте его.
3. Запустите приложение:
   - **Для Windows:** запустите `Umbra.exe`.
   - **Для Mac:** запустите `Umbra.app`. При первом запуске кликните по приложению правой кнопкой мыши (или зажмите `Control`) и выберите «Открыть», чтобы обойти блокировку скачанных из интернета файлов.
   - **Для Linux:** запустите файл `Umbra` (может потребоваться дать права на выполнение `chmod +x Umbra`).
4. *(При первом запуске программе может потребоваться несколько секунд для распаковки встроенных нейросетей, это нормально).*

## 🛠 Как собрать проект из исходников (для разработчиков)
1. Убедитесь, что установлен Python 3.14 и зависимости (`requirements.txt`).
2. Перейдите в папку с кодом:
   ```cmd
   cd src
   ```
3. Запустите скрипт сборки:
   ```cmd
   python build.py
   ```
   Готовый `Umbra.exe` будет создан в корневой папке проекта.
