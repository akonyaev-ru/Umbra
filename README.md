# 🛡️ Umbra

![Python](https://img.shields.io/badge/python-3.14-blue)

![Platform](https://img.shields.io/badge/platform-Windows%20%7C%20macOS%20%7C%20Linux-lightgrey)

**Umbra** — это локальная десктоп-утилита для Windows, macOS и Linux, предназначенная для **анонимизации** юридических документов (`.docx`, `.pdf`, `.xlsx`, `.txt`, `.csv`, `.html`, а также `.doc` на Windows). Программа заменяет чувствительные данные на категорийные метки (например, `[ФИО_1]`, `[ОРГАНИЗАЦИЯ_2]`), а также умеет **деанонимизировать** их — подставлять реальные данные обратно в документ (например, при обработке ответа от ИИ). Формат `.md` используется как формат **экспорта** для передачи текста нейросети (и как формат ответа ИИ при восстановлении), а не как входной документ.

![Umbra Screenshot](src/screenshot.jpg)

## ✨ Особенности
* **Работает полностью офлайн:** без интернета и серверов, данные никогда не покидают компьютер.
* **Универсальность:** подходит для любых документов, договоров и соглашений.
* **Поддержка Markdown:** полная поддержка экспорта в `.md` для удобной передачи текста нейросетям.

## 💻 Технологии
* **Язык:** Python 3.14 (64-бит)
* **Интерфейс:** `customtkinter` (с поддержкой Drag-and-Drop на Windows через `windnd`)
* **NLP (Обработка текста):** `navec` (эмбеддинги), `slovnet` (NER), `razdel` (проект Natasha)
* **Работа с документами:** `python-docx`, `pypdf`, `openpyxl`, `markdown-it-py`
* **Взаимодействие с ОС:** `pywin32` (поиск открытых файлов и конвертация `.doc` — только для Windows), `psutil`
* **Сборка:** `PyInstaller` (в один файл `Umbra.exe` для Windows, `Umbra.app` для macOS и `Umbra` для Linux)

## 📁 Структура проекта
* `Umbra.exe` — готовая скомпилированная программа.
* `src/` — папка со скриптами, моделями и исходниками интерфейса.

## 🚀 Установка и запуск (для пользователей)

1. Перейдите в раздел **Releases** на GitHub.
2. Скачайте нужную версию:
   - **Для Windows:** скачайте `Umbra-Windows.zip`, распакуйте архив и запустите `Umbra.exe`.
   - **Для Mac:** скачайте `Umbra-macOS.tar.gz`, распакуйте архив. При первом запуске `Umbra.app` кликните по приложению правой кнопкой мыши (или зажмите `Control`) и выберите «Открыть», чтобы обойти блокировку скачанных из интернета файлов.
   - **Для Linux:** скачайте `Umbra-Linux.tar.gz`, распакуйте архив и запустите файл `Umbra` (может потребоваться дать права на выполнение `chmod +x Umbra`).
3. *(При первом запуске программе может потребоваться несколько секунд для распаковки встроенных нейросетей, это нормально).*

## 🛠 Как собрать проект из исходников (для разработчиков)
1. Убедитесь, что установлен Python 3.14 и зависимости (`requirements.txt`).
2. Перейдите в папку с кодом:
   ```cmd
   cd src
   ```
3. Запустите скрипт сборки:
   ```cmd
   python build.py
   ```
   Готовый `Umbra.exe` будет автоматически перемещен в корневую папку, заменив старую версию.
